# 沈现周 · 美食摄影与影像创作

成都美食摄影师、编导与影像创作者沈现周的个人站点。用镜头讲述食物的故事。

## 本地预览

```bash
npm install
npm run dev
```

浏览器打开终端里给出的本地地址。开发与构建都使用站点前缀 `/shen-portfolio/`。

## 说明

首页第一屏是预先渲染的形象短片，字放在画面左侧的暗部。服务一栏在导演、摄影、剪辑、调色之间切换预先渲染的定格。作品按一条序列来看：十七张菜品照片，以及新片场上的三支影片。关于保留轮廓光短片和全身设定。联系方式只有邮箱。字体（Kanit、Noto Sans SC、Noto Serif SC）放在站点里，不从外部字体服务加载。
