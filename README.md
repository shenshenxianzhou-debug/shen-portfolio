# 沈现周 · 美食摄影与影像创作

成都美食摄影师、编导与影像创作者沈现周的个人站点。用镜头讲述食物的故事。

## 本地预览

```bash
npm install
npm run dev
```

浏览器打开终端里给出的本地地址。开发与构建都使用站点前缀 `/shen-portfolio/`。

## 说明

作品区为实地拍摄的菜品与过程照片。影像区链向新片场上的三支影片与个人主页。联系方式只有邮箱。
