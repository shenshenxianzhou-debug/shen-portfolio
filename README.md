# 沈现周 · 美食摄影与影像创作

成都美食摄影师、编导与影像创作者沈现周的个人站点。用镜头讲述食物的故事。

## 本地预览

```bash
npm install
npm run dev
```

浏览器打开终端里给出的本地地址。开发与构建都使用站点前缀 `/shen-portfolio/`。

## 说明

首页按整屏章节来排：开场、一句苏轼的词、十七张菜的画廊、四项工作、三支新片场影片、关于，以及邮箱。预先渲染的形象只出现在关于里。字体放在站点里，不从外部字体服务加载。联系方式只有邮箱。
