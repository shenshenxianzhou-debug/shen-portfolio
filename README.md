# 灵活的左撇子

美食摄影与影像站点。用镜头讲述食物的故事。关于页里的个人介绍使用本人姓名。

## 本地预览

```bash
npm install
npm run dev
```

浏览器打开终端里给出的本地地址。开发与构建都使用站点前缀 `/shen-portfolio/`。

## 说明

首页、作品集、关于是三个页面。作品集保留新片场上的三支影片，摄影按菜品、场景、饮品分组。关于页保留个人介绍。预先渲染的形象只出现在关于里。字体放在站点里，不从外部字体服务加载。
