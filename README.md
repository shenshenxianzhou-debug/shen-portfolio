# 沈现周 · 美食摄影与影像创作

成都美食摄影师、编导与影像创作者沈现周的个人站点。用镜头讲述食物的故事。

## 本地预览

```bash
npm install
npm run dev
```

浏览器打开终端里给出的本地地址。开发与构建都使用站点前缀 `/shen-portfolio/`。

## 说明

首页轮播实地拍摄的菜品。作品里，照片目前放在「美食」；三支影片与新片场主页放在「视频 / 美食 · 餐饮」。其余分类先空着。联系方式只有邮箱。
